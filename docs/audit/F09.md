# F09 — Shared Zola readiness probe

Doctor probes the executable it resolved with the same version parser and minimum-version policy as runtime. Old versions, malformed output and nonzero version-command exits fail with contextual errors rather than a panic. The existing minimum version is unchanged; newer compatible semantic versions are not artificially pinned away.

Tests cover exact minimum/newer versions, prereleases below the minimum, missing/malformed output, explicit executable selection and exit propagation. Executable acceptance confirms that both doctor and build reject old and malformed version responses without panic. Bootstrap installer behavior is not redesigned by this change.
