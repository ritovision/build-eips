# F08 — Preview URL and output-root contract

URL paths are UTF-8 percent-decoded exactly once before component validation. Malformed escapes, controls, encoded separators, backslashes, drive/alternate-stream colons and traversal are rejected consistently. Valid space/Unicode/literal-percent filenames resolve normally. Candidate files are canonicalized under the output root, and output links are allowed only when they resolve within that root. Special files such as FIFOs are not opened as preview assets.

The opened file uses the confined canonical destination; MIME selection and diagnostics keep the requested filename. Windows canonical-path prefixes do not become part of the URL/path interface.

Unit and real HTTP acceptance cover encoded assets, an ordinary control, literal/encoded traversal, file and directory escape links, an allowed internal link, malformed requests and FIFOs. The server still binds according to existing configuration. This is a static-path confinement boundary, not protection against an adversarial same-user process replacing files between canonicalization and opening. Native Windows acceptance is separate.
