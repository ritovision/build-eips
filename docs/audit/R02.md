# R02 — Tree-shape convergence

Filesystem synchronization now plans removals, directory creation and file writes as a batch. Obsolete descendants are normalized behind a replacing parent. Paths below a regular file are absent; link ancestors are not followed. Git indexes remove previous entries before new files are admitted. The same planner is used for raw staging, live publication and one-shot dirty materialization.

Publication I/O failures retain retry state; valid subsequent input is compared to the last successful generation. The real HTTP regression switches directory→file→directory, makes ordinary edits after both transitions and injects a real generated-directory permission failure followed by recovery. Atomic multi-file HTML publication is not claimed.

Static membership/shape transitions also normalize the disposable output paths and touch the mounted Zola config after successful publication, forcing a full renderer refresh. This closes the independently observed stale output directory failure; ordinary nonstructural edits keep the existing incremental path.
