# R04 — Shared Git-entry conflict contract

Fresh merges and live sibling admission now call the same mode/kind/object-identity predicate. Live disk identity uses Git's owner-executable normalization and preserves indexed executable mode on platforms whose generated index disables filemode trust. Link blobs use link text, not target bytes; broken links are not mistaken for deletion. Sibling insertion now preserves the mode that was actually compared rather than converting every entry to regular Blob.

The real fresh/live differential cases cover bytes, executable mode and symlink/regular transitions, conflict recovery and deletion while the fixed sibling contribution remains. Local forks and fixed-startup sibling semantics are unchanged. Native Windows filesystem acceptance remains distinct from Linux testing.
