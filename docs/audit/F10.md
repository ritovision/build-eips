# F10 — Executable documentation alignment

The embedded workspace guide and coordinated EIPs/ERCs/theme READMEs use the actual `--interface` argument and command-local `--clean` placement. Clean mode requires a clean active source; it does not discard work or replace the editable local theme. No CLI aliases or changed product semantics were introduced.

The parser regression extracts documented build-eips invocations. The downstream README regression is explicitly opt-in because other repositories are not fixtures in every checkout:

```
BUILD_EIPS_DOC_PATHS=/path/EIPs/README.md:/path/ERCs/README.md:/path/theme/README.md cargo test consuming_repository_readme_commands_parse -- --ignored
```

Run the Rust suite plus that explicit test when reviewing the coordinated documentation branches. Generated WORKSPACE.md is not hand-edited; future init generates it from the corrected embedded source.
