# R03 — Configuration provenance

The active manifest and workspace configuration retain the exact bytes parsed at resolution. Prepared runtime and live sessions carry that snapshot; they do not reconstruct it from a Git commit or re-sample it after watching begins. Local-only manifests retain their ordinary-build support. Configuration changes between resolution, watcher installation and publication fail with a restart diagnostic; restoring the original snapshot permits recovery. Workspace config edits are watched as well as active source edits.

The four real-server startup cases are committed, dirty tracked, newly staged and local-only Build.toml. The pure snapshot test verifies changes between resolution and startup are rejected. No requirement that developer configuration be tracked was introduced.
