# R01 — Effective generated Git ownership

Generated repository opens now validate real .git storage plus the Git handle’s effective canonical workdir, metadata/common directory and index path. Metadata links are rejected before opening; redirections such as core.worktree fail before fetch/checkout/index mutation, rather than being repaired. Source-repository opens are unchanged and linked developer worktrees remain supported. Private live staging uses the same generated-repository validator.

The bound is deterministic metadata redirection, not arbitrary same-user concurrent replacement. Regression coverage includes redirected workdirs, metadata links and valid reuse; executable tests preserve external sentinels and assert no proposal was written outside the owned root.
