# R05 — Theme source generations

Editable themes now use shared HEAD/index/tracked-membership and filesystem transition primitives, rather than the old dirty-path union. Theme source state is privately staged before publication; no proposal parsing or sibling merge is imposed on it. Clean branch transitions, stage/unstage, deletion/restoration and linked source worktrees are observed through the same Git event routing as active content. Stale static output membership is invalidated before a full renderer refresh when necessary.

Startup reconciles the mounted input after watcher installation and verifies source HEAD/index/file timestamps around staging. Configuration provenance applies to both content and theme events, including clean-active-source serving. Failed publication retains pending retries. This does not claim validated last-good HTML for arbitrary invalid theme templates or atomic multi-file publication.
